🔒 MCP Secure — Feature 3

Version Change Watcher

The watcher monitors published servers for content changes. When the content fingerprint changes, an automatic re-scan is triggered and the old attestation is marked superseded. Demonstrates Figure 2 of the MCP Secure overview.

How the watcher works: 📄 Docs-only update → commit SHA changes, but content fingerprint stays the same → verdict carried forward, no re-scan. ☠ Bait-and-switch update → fingerprint changes → status: change_detected → automatic re-scan → new versioned attestation → old PASS marked superseded.
